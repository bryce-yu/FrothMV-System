# FrothMV-Supervisory-System

## Description
Python-based machine vision edge analytics system for froth flotation monitoring and supervisory integration.

## Setup

Create virtual environment:

```powershell
python -m venv venv
```

Activate:

```powershell
.\venv\Scripts\Activate.ps1
```

Install dependencies:

```powershell
pip install -r requirements.txt
```
